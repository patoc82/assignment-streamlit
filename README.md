# assignment-streamlit

# Customer Order Entry App

## A Streamlit web application to place, verify, and view customer orders stored in Supabase.

# Setup Instructions

## Install dependencies:

### pip install -r requirements.txt


## Configure Environment Variables:
### Create a .env file in the main folder with your credentials:

### APP_PASSWORD=your_classroom_password
### SUPABASE_URL=your_supabase_url
### SUPABASE_KEY=your_supabase_key


## Run the App:

### streamlit run app.py
